# test-datasets
Test data set to evaluate the KMER COMPARISON technical application in nf-eit modules repository

# Files:
- Synthetic assembly: contig.fasta
- synthetic read 1: fastq_1.fastq
- synthetic read 2: fastq_2.fastq
- binary kmer read count files: test_reads_short_k5.kmc_pre, test_reads_short_k5.kmc_suf
- binary kmer assembly count files: test_assembly_short_k5.kmc_pre, test_assembly_short_k5.kmc_suf
- binary read only files: test_reads_only_short.kmc_pre, test_reads_only_short.kmc_suf
- text kmer read count files: Klebsiella_pneumoniae_19151_reads_short_k21_dump.sorted.txt
- text kmer assembly count files: Klebsiella_pneumoniae_19151_assembly_short_k21_dump.sorted.txt
- text read only files: Klebsiella_pneumoniae_19151_reads_only_short_dump.sorted.txt
- text assembly only files: Klebsiella_pneumoniae_19151_assembly_only_short_dump.sorted.txt
- text shared only files: Klebsiella_pneumoniae_19151_shared_short_dump.sorted.txt
- summary tsv file: test_summary.tsv
